اتصالات البيانات والشبكات

الفصل الأول: المقدمة والمفاهيم الأساسية

1. المقدمة Introduction

Data Communications اتصالات البيانات: تبادل البيانات (على شكل أصفار وآحاد) بين جهازين عبر وسط نقل مثل الكابلات.

Local الاتصال المحلي يحدث عادةً وجهًا لوجه، أما Remote فيحدث عبر مسافات.

Telecommunication الاتصال عن بُعد؛ كلمة Tele يونانية تعني «بعيد»، وتشمل الهاتف والتلكراف والتلفزيون.

الخصائص الثلاث الأساسية

Delivery

التسليم: تصل البيانات إلى الوجهة الصحيحة فقط، وتُستقبل من الجهاز أو المستخدم المعني حصراً.

Accuracy

الدقة: البيانات التي تتغير أثناء النقل دون تصحيح تصبح غير صالحة.

Timeliness

التوقيت: البيانات المتأخرة بلا فائدة.

Real-time Transmission النقل المباشر: تسليم الصوت والفيديو فور إنتاجها وبنفس الترتيب ودون تأخير ملحوظ.

4. فوائد الشبكات Why Networks

Resource Sharing مشاركة الموارد: طابعة ليزرية مشتركة في مكتب، أو برمجيات وبيانات.

Client-Server العميل والخادم: يرسل العميل طلباً عبر الشبكة، فينفذه الخادم أو يبحث عن البيانات ويعيد الرد.

تقريب المسافات: عبر الإنترنت يصبح العالم قرية صغيرة.

E-Commerce التجارة الإلكترونية: البيع والشراء عبر الإنترنت.

Mobile Network شبكات الهاتف المحمول: الاتصالات اللاسلكية الأكثر استخداماً اليوم.

5. أنماط تدفق البيانات Data Flow Modes

Simplex أحادي الاتجاه: أحد الطرفين يرسل فقط والآخر يستقبل فقط (مثل الحاسوب الرئيسي والشاشة).

Half-Duplex نصف مزدوج: كل طرف يرسل ويستقبل، لكن ليس في نفس الوقت.

Full-Duplex مزدوج كامل: الإرسال والاستقبال في وقت واحد.

6. الشبكة والمعالجة الموزعة Network & Criteria

Network الشبكة: مجموعة أجهزة (عُقد) مرتبطة عبر روابط وسائط (قنوات اتصال).
Node العُقدة: أي حاسوب أو طابعة أو جهاز يرسل أو يستقبل بيانات الأجهزة الأخرى.

Distributed Processing المعالجة الموزعة: تُقسَّم المهمة على عدة حواسيب؛ بدل جهاز ضخم واحد يتولى كل حاسوب جزءاً فرعياً من العملية.

معايير تقييم الشبكة Network Criteria

Performance

الأداء: يعتمد على عدد المستخدمين، نوع الوسائط، الأجهزة، وكفاءة البرامج.

يُقاس بـ Delay التأخير وThroughput معدل النقل.

Reliability

الموثوقية: تعتمد على معدل أعطال المكونات.

تُقاس بـ Availability التوفرية وRobustness المتانة.

Security

الأمان: حماية البيانات من التلف أو الفقدان بسبب الأخطاء الفنية أو المستخدمين الخبثاء.
